# مركز الضباب للعلاج الطبيعي — DPTC (Demo)

نسخة عرض (واجهة أمامية) لموقع **مركز الضباب للعلاج الطبيعي (DPTC)** في السليمانية، الرياض. Vue 3 + Vite، عربي/إنجليزي.

## التشغيل
```bash
npm install
npm run dev
```
الرفع على Vercel: GitHub ثم Import (Build: `npm run build`، Output: `dist`).

## الأصول (`public/img/`)
من صور المركز على خرائط Google: الاستقبال ولافتة DPTC النيون، صالة التأهيل الزرقاء، صالة التمارين، العلاج اليدوي، غرفة العلاج، ومبنى فندق الضباب ورويك (لافتة DPTC على المبنى).
استبعدت صوراً لمراكز أخرى ظهرت على صفحتهم (KUUR، مجمع المحترفين…) وصوراً غير مرتبة لغرف العلاج.
العلامة (Wordmark) مرسومة SVG بروح لافتة النيون الزرقاء. موقعهم الحالي dptc.me دومينه غير موجود، ولم أجد لهم حساباً على السوشيال ميديا.

## ميزة خاصة
خريطة جسم تفاعلية: يضغط الزائر على مكان الألم فيرى كيف يعالجه المركز، وينتقل اختياره لنموذج الحجز على واتساب.

## تنبيهات
- قائمة الحالات (الرقبة، الظهر، الركبة…) معتادة لمراكز العلاج الطبيعي، وليست من موقعهم — تأكد منها.
- مراجعاتهم على Google مختلطة (فيها شكاوى عن الخصوصية والتنظيم)، لذلك لم أعرض اقتباسات، فقط التقييم 4.5 (121).
- الأوقات (السبت–الخميس 1–10 م، الجمعة مغلق) والهاتف والعنوان من Google. "الدور السادس" من رقم الطابق الظاهر في صورة الاستقبال.

## قبل الإطلاق الرسمي
احذف `noindex` من `index.html` وشريط "نسخة عرض" من `src/App.vue`.
